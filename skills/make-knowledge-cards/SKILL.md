# Make Knowledge Cards

## Overview

将长文本文章转换为精简、可复习的知识卡片，每张卡片只承载一个独立知识点，帮助用户快速提炼核心内容并用于后续记忆和复习。

## Input Requirements

接受以下两种输入形式：
1. 用户直接粘贴的文章文本
2. 本地路径的Markdown（.md）或纯文本（.txt）文件

**不接受的输入**：网页URL、PDF文件、需要登录或抓取的在线内容。遇到这些输入时明确告知用户暂不支持，请用户提供纯文本或文件路径。

## Workflow

### Step 1: 获取并确认输入
- 如果用户提供文件路径，先读取文件全文
- 如果用户直接粘贴文本，直接使用该文本
- 快速浏览全文，判断文本长度和信息密度
- 如果文本过短（少于200字）或信息密度不足以生成5张卡片，直接告知用户当前内容能生成N张卡片（N<5），不强行凑数

### Step 2: 识别核心知识点
通读全文后，提取真正重要的知识点：
- 概念定义
- 关键结论
- 核心方法论
- 重要数据或事实
- 有实用价值的操作建议

**判断标准**：
- 这个知识点是否值得单独记一张卡片？
- 删除这个知识点是否会让读者错过文章的核心价值？
- 是否与其他知识点重复？

**严格遵守**：
- 绝对不编造原文中没有的信息
- 不加入自己的评论、引申或无关背景知识
- 合并重复表述，同一概念只保留最清晰的一张卡片
- 优先保留独特、有信息量的内容，删除过渡性、铺垫性文字

### Step 3: 控制卡片数量
- 目标范围：5~8张
- 如果核心知识点超过8个，只保留最重要的8个，合并高度相关的内容
- 如果核心知识点不足5个，有多少就输出多少，绝不硬凑
- 宁少勿滥：空泛、无实质内容的卡片宁可不要

### Step 4: 生成每张卡片
每张卡片严格遵循以下结构：

```
## 卡片N: [卡片标题]

**核心知识**: [一句话陈述这个知识点的核心结论，不超过30字]

**简明解释**: [2~3句话解释这个概念/结论，用通俗的语言讲清楚，不要照搬原文长句，要做提炼]

**例子/自测问题**: 
- 例子: 从原文中找一个对应的具体例子/数据/场景，或者
- 自测问题: 一个可以检验是否掌握这个知识点的简短问题
```

**卡片编写规则**：
- 一张卡片只讲一个知识点，不要把多个概念塞进同一张卡片
- 标题要清晰具体，能直接概括卡片内容
- 核心知识必须是陈述句，直接给出结论
- 简明解释要易懂，不要堆砌术语
- 例子必须来自原文；如果原文没有合适例子，可以换成自测问题
- 所有内容必须忠实于原文，不得添加原文不存在的解释

### Step 5: 输出格式
按以下格式直接输出所有卡片，不需要额外前言或总结：

先一行说明：
> 本文共提取出 N 张知识卡片：

然后逐张输出卡片，卡片之间空一行分隔。

## Quality Checklist

输出前自查：
- [ ] 每张卡片只讲一个知识点
- [ ] 没有重复内容
- [ ] 所有内容都能在原文中找到依据，没有编造
- [ ] 卡片数量在合理范围，没有强行凑数
- [ ] 核心知识部分简短有力
- [ ] 解释通俗易懂，不是原文长句复制粘贴
