# make-knowledge-cards

一个开源的AI Skill，用于将长文章快速转换为结构化知识卡片，帮助提炼核心知识点、降低复习成本。

## 1. 项目解决什么问题

在阅读长文、技术文档、学习材料时，常见的痛点是：
- 文章太长，读完记不住核心要点
- 手动整理笔记耗时耗力，容易遗漏重点
- 复习时面对大段文字效率低下，缺乏可快速回顾的结构化材料
- 网上很多AI总结会编造原文不存在的信息，或者把多个知识点混在一段里

本Skill专门解决"长文快速提炼为可复习知识卡片"的问题，严格基于原文内容生成标准化卡片，不编造、不凑数，帮助用户把输入的文本快速转化为适合记忆和复习的知识点集合。

## 2. 主要功能

### 核心能力
- **自动知识点提取**：通读全文后自动识别真正重要的概念、结论、方法论，过滤铺垫性、重复性内容
- **单卡片单知识点**：每张卡片只讲一个独立知识点，避免信息混杂
- **标准化卡片结构**：每张卡片固定包含标题、核心知识、简明解释、例子/自测问题四个部分
- **忠实原文**：所有内容均来自输入文本，绝不编造原文不存在的信息
- **智能数量控制**：目标生成5~8张卡片；核心内容不足5张时按实际数量输出，不强行凑数；超过8张时自动保留最重要的内容

### 输入支持
- 直接粘贴的文章文本
- 本地Markdown（.md）或纯文本（.txt）文件

### 暂不支持的能力
- 网页URL自动抓取（需用户自行粘贴正文或提供本地文件）
- PDF文件处理
- Anki格式导入导出
- 图形化界面操作

## 3. 安装方法

本Skill为纯文本定义，无额外依赖，安装步骤：

1. 将整个 `skills/make-knowledge-cards` 文件夹复制到你的Skill搜索路径下
2. 确保目录结构完整：
   ```
   make-knowledge-cards/
   ├── SKILL.md              # Skill核心定义与工作流程
   └── agents/
       └── openai.yaml       # Agent配置元数据
   ```
3. 无需安装任何Python依赖或第三方工具，AI Agent读取SKILL.md后即可直接使用

## 4. 使用方法

### 触发方式
当你需要把长文、文章、笔记整理成知识卡片时，直接对AI提出需求，例如：
- "把这篇文章做成知识卡片"
- "帮我把这段内容提炼成可复习的卡片"
- "读取这个文件，生成知识点卡片"

### 输入方式
二选一即可：
1. 直接把需要提炼的文章全文粘贴到对话中
2. 提供本地 `.md` 或 `.txt` 文件的绝对路径，由AI读取文件内容

### 输出格式
Skill会自动按以下格式输出所有卡片：
1. 开头一行说明总卡片数
2. 逐张输出卡片，每张卡片结构固定：
   - 卡片标题
   - 核心知识：一句话核心结论
   - 简明解释：2~3句通俗化解释
   - 例子/自测问题：来自原文的具体例子，或用于检验掌握程度的问题

## 5. 输入输出示例

### 输入示例（片段）
> 番茄工作法是用固定时长工作段配合强制休息，维持注意力的时间管理方法。标准的番茄工作法分为四个阶段：选择任务后将计时器设定为25分钟，期间专注于该任务，计时器响起后休息3到5分钟。每完成四个25分钟工作段，就可以进行15到30分钟的长休息。
